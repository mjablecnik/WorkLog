## Decisions made
- **`createProject`'s store-level `billable` parameter defaults to `true`** (`billable: boolean = true`) rather than being strictly required as design.md's literal signature shows. Several existing test call sites (`tests/lib/server/store/{schema,activities,aggregates}.test.ts`, `tests/api/{sessions,days}.test.ts`) call `createProject(tx, name)` with two arguments and are not in task 4.7's fixture-repair list; making the parameter optional avoids an unlisted, out-of-scope breakage while still fully implementing the feature (Requirement 1.1's own default applies at this layer too).
- **The Activity Dialog's project-field label** (`"project (paid)"` / `"project (unpaid)"`) is built as a template string from the existing `activity_field_project` key plus `category_paid`/`category_unpaid`, not a new dedicated message key — satisfies Requirement 10.9's "the project field's label names the active filter" without inventing new catalogue entries for a detail the design document left unspecified.
- **E2E validation ran against a locally-provisioned, ephemeral PostgreSQL container** (`worklog-e2e-pg`, on the sandbox's own Docker network, reached by container name per the `sandbox-docker-net` skill — the project's own `scripts/test-e2e.sh` publishes a host port this sandbox cannot reach) rather than through `bun run test:e2e:local` directly. All Playwright runs used a real `bun run build` + `bun run preview` webServer, real Chromium, real migrations. The container was torn down before this phase closed; nothing sandbox-specific was left in the repository.
- **Two real UI regressions found via E2E were fixed in-place** (see What changed) rather than merely logged, since they were caused by this run's own additions and are genuinely in scope, unlike the two pre-existing issues logged instead.
- **The `verify` phase's env setup**: no `TEST_DATABASE_URL`/`worklog-pg` state was left behind by this phase — the project's own long-running `worklog-pg` container (used for `bun run test`) is untouched and still running; the ephemeral `worklog-e2e-pg` container used only for this phase's own E2E validation was removed.
